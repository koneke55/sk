# Portfolio Jobs

A modern React portfolio website built with Vite, TypeScript, and Tailwind CSS.

## Overview  

This project is a personal portfolio site showcasing skills, experience, projects, and contact information. It includes reusable UI components, responsive layout, animated interactions, and a clean developer experience.

## Tech stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Custom components and UI utilities

## Structure

- `src/` — application source code
- `src/components/` — page sections and UI components
- `src/hooks/` — custom React hooks
- `src/lib/` — asset and utility modules
- `public/` — static assets and public files

## Features

- Responsive portfolio layout
- Hero section with animated text
- About, experience, projects, achievements, and contact sections
- Custom reusable component library
- Tailwind-based styling and theming

## Run locally

```bash
npm install
npm run dev
```
